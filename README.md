**RTHuds** is a modern, flexible, and fully modular HUD system for Minecraft. Instead of focusing on survival-specific indicators, it provides a clean and general interface foundation suitable for different gameplay styles. Each HUD element can be toggled individually, allowing players to create simple or detailed layouts based on their preferences.

The main goal of RTHuds is to give players full control over their visual experience. Its organized structure enables easy customization, repositioning, and personalization of on-screen information. Designed with performance and stability in mind, it runs smoothly even on lower-end systems and offers an accessible configuration system for both beginners and advanced users.
